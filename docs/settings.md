# Settings

azooKeyは以下のような設定項目を持っています。

TBW

## 学習のリセット

学習のリセットは「一度限り実行する」という都合上、例外的な実装になっています。

TBW

## 片手モードで解除ボタンを表示しない

- `Bool`(default: `false`)

片手モードでは通常「解除」と「調整」のボタンが表示されますが、これを非表示にすることができます。

## キーボードの高さ

キーボードの高さは倍率で設定できます。

「倍率」で実装したのは、「高さそのもの」や「差分」による実装が機種依存になることに由来します。

## フリックの感度

フリックの感度は倍率で設定できます。

## フォントサイズ

キーと変換候補のフォントサイズは絶対値で指定できます。デフォルト値は「-1」であり、この場合自動で設定されるようになっています。自動で設定する場合はキーの大きさに応じて動的にフォントサイズを調整することがあります。

## キーボードのフィードバック

キーボードのフィードバックは「音」と「振動」があり、それぞれ独立に設定できます。「振動」はAPIの制限のため、フルアクセスが必要です。

## クリップボードの履歴を保存

フルアクセスがオンである場合、クリップボードの履歴を追跡し、保存することができます。保存されたクリップボードの履歴は専用のタブで確認できます。

この設定を有効にすると、自動で「コピーの履歴」というボタンがタブバーに追加されます。無効にすると削除されます。

## ペーストボタン

フルアクセスがオンであり、かつフリック入力で左下に「地球儀キー」ではなく「カーソルバーキー」がある場合、カーソルバーキーの上フリックにペーストボタンを追加できます。

なお、ペースト自体はアクションであるため、カスタムキーやカスタムタブのアクションとして設定することができます。

## 変換に連絡先データを利用

「連絡先」アプリの氏名のデータを変換に利用します。知り合いの名前が打ちやすくなります。

なお、この機能にはフルアクセスと「連絡先」アプリへのアクセスの許可が必要です。

## 日英混在入力（ベータ版）

- `Bool`(default: `false`)

ローマ字入力中に打った英単語を、英字のまま入力します。日本語と英語を切り替えずに打てます。

```
kyouhagoogledekensaku    → きょうはgoogleでけんさく
ashitanomeetingwotsuika  → あしたのmeetingをついか
```

英字を打つたびに、末尾に続けて打った英字の並びを日本語の区間と英語の区間に分け、英語の区間だけをダイレクト入力に切り替えます。判定の手順は次のとおりです。

1. 英字の各位置を区切りの候補にし、日本語の音節（`kyo`、`u`、`ha` など）と英単語（`google` など）をノードにしたラティスを作ります。
2. 日本語のノードには、ローマ字として読みにくいほど大きいコストを付けます。母音のない子音（`google` の `g`）や、日本語ではまず打たない音節（`gwo`、`le`）が該当します。
3. 英語のノードと、日本語と英語の切り替えにもコストを付け、合計が最小になる区切りを選びます。

ローマ字として自然に読める語（`tomato`、`sake`）は、英単語でも日本語のままにします。キャレットの前が英文（`I want `）のときは、英単語を優先します。

英単語かどうかは、まず同梱の辞書（`BuiltInEnglishWords`）を小文字で引き、載っていなければOSのスペルチェッカー（`UITextChecker`）で調べます。スペルチェッカーは製品名やサービス名を正しい大文字小文字でしか認めない（`iPhone`は正しく、`iphone`は誤り）ので、小文字で打つ語を同梱の辞書で補います。同梱の辞書の固有名詞は、次のように扱います。

- 5文字以上の固有名詞（`amazon`、`notion`）は、ローマ字として読めても英語にします。4文字以下の固有名詞（`java`）は日本語の語と重なりやすいので、ほかの英単語と同じように、ローマ字として読めれば日本語のままにします。
- 入力中は打ったとおり（`iphoneをかった`）に表示し、変換候補ではその次に正しい表記（`iPhoneを買った`）を出します。

英字は1文字ずつ別の語として変換されるので、英単語の途中で切れる候補（`python`の`p`だけの候補）は出しません。ライブ変換で最初の文節を自動で確定するときも、英単語を1つの文節として扱います。

実装は `AzooKeyCore/Sources/KeyboardExtensionUtils/MixedLanguageInput` にあります。
